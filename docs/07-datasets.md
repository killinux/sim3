# 可用公开数据集

## 短视频推荐数据集

### 1. KuaiRand（推荐首选）

**来源**: 快手（最接近抖音的平台）

| 属性 | 详情 |
|------|------|
| 用户数 | 27,285 |
| 视频数 | 3200万 |
| 交互数 | 3.22亿 |
| 观看时长 | 有（毫秒级精度） |
| 参与信号 | **12种**: click, like, follow, comment, forward, hate, long_view + 多个连续变量 |
| 特殊价值 | **随机曝光数据** —— 无偏评估（不受推荐算法选择偏差影响） |

**子集**: KuaiRand-1K（1000 用户），适合快速原型验证

**为什么是首选**:
- 快手与抖音同为短视频平台，用户行为模式最接近
- 12 种反馈信号远超其他数据集
- 随机曝光子集可做无偏校准基准
- KuaiRand-1K 的 1000 用户恰好对应 1000 agent 的设计

### 2. KuaiRec

**来源**: 快手

| 属性 | 详情 |
|------|------|
| 用户数 | 7,176 |
| 视频数 | 10,728 |
| 交互数 | 1250万 |
| 观看时长 | 有（毫秒级精度） |
| 参与信号 | like, comment, follow, share, download + 社交图谱 |
| 特殊价值 | **99.6% 交互密度** —— 几乎完整的用户-视频交互矩阵 |

**用途**: 密集交互的 ground truth 评估

### 3. VK-LSVD

**来源**: VK（俄罗斯社交平台）

| 属性 | 详情 |
|------|------|
| 用户数 | 1000万 |
| 视频数 | 2000万 |
| 交互数 | **407亿** |
| 观看时长 | 有（截断在 255s） |
| 参与信号 | like, dislike, bookmark, share, profile_click, comment_open |
| 许可 | Apache 2.0 |

**用途**: 大规模压力测试，规模最接近真实场景

### 4. MicroLens

**来源**: 学术研究

| 属性 | 详情 |
|------|------|
| 用户数 | 3400万 |
| 视频数 | 100万 |
| 交互数 | **10亿** |
| 观看时长 | 有限 |
| 参与信号 | views, likes, comments |
| 特殊价值 | 提供完整视频内容（可做多模态特征提取） |

**用途**: 多模态内容理解、超大规模评估

## 电影/通用推荐数据集（备选参考）

### MovieLens-1M

- 6040 用户 × 3900 电影 × 100万评分
- Agent4Rec 的评估数据集
- 适合对标 Agent4Rec 复现

### Open Bandit Dataset (ZOZO)

- 2600万条记录
- 提供真实 ground truth 和倾向得分
- 适合验证 OPE 估计器

## 推荐的数据使用路线

| 阶段 | 数据集 | 目的 |
|------|--------|------|
| **概念验证** | KuaiRand-1K (1000用户) | 快速验证 agent 架构和模拟流程 |
| **保真度评估** | KuaiRec (密集矩阵) | 在几乎完整的交互数据上评估模拟精度 |
| **规模测试** | KuaiRand-Full (27K用户) | 测试聚类/权重/缩放方法 |
| **压力测试** | VK-LSVD (1000万用户) | 验证大规模下的性能和分布 |
| **OPE 验证** | Open Bandit Dataset | 验证离策略评估方法的准确性 |
| **真实上线** | 抖音脱敏数据 | 最终校准和生产使用 |
